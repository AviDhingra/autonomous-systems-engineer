How it works

Every job runs the same governed loop. The frontier model does the reasoning; plain Python decides what happens.

  1. Propose ({{ actors.model.label }}): investigates the bug and proposes one file change.
  2. Apply ({{ actors.python.label }}): writes the change, after saving the original so it can be rolled back.
  3. Verify ({{ actors.python.label }}): runs pytest, Ruff and mypy. Passing means the job succeeds.
  4. Judge ({{ actors.jev.label }}): if verification fails, JEV is asked whether the failure is worth retrying.
  5. Decide ({{ actors.policy.label }}): policy weighs JEV's answer against the retry and time budgets, then retries (rolling back first), escalates to a person, or fails the job.

Checkpoints make it recoverable

Each step is recorded before it starts and after it finishes. If the process dies, the job resumes at the first step without a durable result: completed work is never redone.

How it works

Every job runs the same governed loop. The frontier model does the reasoning. Plain, deterministic Python decides what happens, and it is the only thing that ever changes a job's state.

Step by step

1 · Propose

The frontier model reads the ticket, searches the code, and proposes one file replacement. That is its whole job.

2 · Apply

Python saves the file's original content, then writes the proposed change, so a failed attempt can always be rolled back.

3 · Verify

Python runs pytest, Ruff and mypy. If all pass, the job succeeds. If not, a decision is needed.

4 · Judge

JEV answers one narrow question: is this failure worth retrying? It returns a classification and a confidence, nothing more.

5 · Decide

Policy checks the budgets first, then weighs JEV's answer. It retries (after rolling back), escalates to a person, or fails the job. If JEV is unavailable or unsure, a fixed rule applies.

6 · Recover

Every step is checkpointed. If the process dies, the job resumes at the first step without a durable result. Completed work is never redone.

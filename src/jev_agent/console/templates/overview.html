A coding agent you can leave running

A frontier model proposes fixes for a real bug. Deterministic Python policy decides what happens next: it checkpoints every step, recovers from crashes, retries within a budget, consults a narrow JEV judgment, and escalates to a person instead of guessing.

  3. JudgeJEV: is this failure worth retrying?
  4. DecidePolicy retries, escalates or stops, within budget
  5. ResolveA person handles what the system won't guess
